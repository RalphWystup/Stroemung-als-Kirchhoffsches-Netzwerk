# Was hier liegt

Ein Strömungslöser (CFD), aufgebaut als Kirchhoffsches Netzwerk — dieselbe Denkweise wie
im `Feld_Labor`, angewandt auf die Navier-Stokes-Gleichungen. Beweisstück ist die
Kármánsche Wirbelstraße am Kreiszylinder bei Re = 100.

| Blatt | Inhalt |
|:--|:--|
| `METHODE_UND_NACHWEIS.md` | die Herleitung und der vollständige Nachweis |
| `BEFUNDE.md` | jeder gefundene Fehler mit der Lücke, die ihn durchgelassen hat |
| `PRUEFPLAN.md` | die Kriterien, aus dem Wortlaut des Auftraggebers abgeleitet |
| `KURZFASSUNG.md` | zwei Seiten Überblick — steht auch als Reiter im Labor |

# Das Labor im Browser

`CFD_Labor_1.6.html` ist **eine einzige Datei**, die ohne Netz läuft — kein Nachladen,
kein CDN. Doppelklick genügt. Neun Reiter:

| Reiter | Was dort geschieht |
|:--|:--|
| **Vergleichsverfahren** | fünf Vergleiche, alle im Browser gerechnet: der Zweigstempel gegen die geschlossene Lösung, die Sprachprobe für Drucknetz und Impulsoperator, der vollständige Löser auf beiden Aufbauten — und **Netzwerk gegen Galerkin**, beide live gerechnet, mit eigener Vernetzung |
| **Zeitverlauf** | drei Schirme übereinander: Weg A, Weg B und ihre Differenz — dazu umschaltbar das angelernte Surrogat gegen die echte Rechnung |
| **Wirbelstraße** | das gerechnete Feldbild, die Netzreihe und die Treppenstreuung |
| **Kurzfassung** | zwei Seiten: Aufgabe, Zielsetzung, Methode (wie die Navier-Stokes-Gleichung zum Netzwerk wird), wie das geprüft wird, wozu das Surrogat, Fazit |
| **Verfahren & Nachweis** | das vollständige Methodenblatt mit allen Formeln (MathML, ohne Netz) |
| **Befunde** | alle Befunde mit der Lücke, die sie durchgelassen hat |
| **Anleitung** | dieses Blatt und der Prüfplan |
| **Programme** | **alle 34 Programme im Wortlaut** — `stroemung/` und `labor/` —, jedes mit Zeilenzahl, Größe und sha256. Wer nachrechnen will, braucht die Quellen, nicht ihre Erwähnung |
| **Lizenz** | was frei ist, was fremd ist, und unter welchen Bedingungen — mit den Bedingungen des Urhebers von Triangle im Wortlaut |

Der Rechenkern `labor/kern_cfd.js` ist eine **zweite Umsetzung** derselben Verfahren und
deshalb gegen die Python-Module geprüft: `node labor/pruefe_kern.js` vergleicht für den
Netzwerkweg 45 Posten, `node labor/pruefe_kern_fem.js` für den Galerkin-Weg 47 Posten
gegen `labor/vergleichsdaten.json`, das aus den geprüften Modulen erzeugt wird. Die
Bedienung wird im echten Browser geprüft: `node labor/pruefe_labor.js` drückt jeden Knopf
und hält die Ergebnisse gegen harte Sollwerte.

## Zum Surrogat

Der Zeitverlauf-Reiter zeigt ein **angelerntes Ersatzmodell**: POD für die Raumformen
(Singulärwertzerlegung der Momentaufnahmen), DMD für den Zeitoperator (Ausgleichsrechnung).
Beides ist geschlossene lineare Algebra, kein Blackbox-Lernen — und es trägt hier, weil
die Wirbelstraße bei Re = 100 in einen **Grenzzyklus** läuft. Man sieht das daran, dass
die Singulärwerte **paarweise** kommen: Jede Frequenz liefert ein Sinus-Kosinus-Paar.

Zwei Dinge dazu, ausdrücklich:

- Das Surrogat gilt **nur** für den Fall, auf dem es angelernt wurde — diesen Zylinder,
  diese Reynoldszahl, den eingeschwungenen Zustand. Nicht für andere Geometrien, nicht für
  den Anlauf.
- Sein Fehler gegen den echten Löser wird **gemessen** und auf der Seite genannt, nicht
  verschwiegen.

# Was man aufrufen kann

Alles liegt in `stroemung\`. Gebraucht werden Python 3 mit NumPy, SciPy und Matplotlib.

**Alles auf einmal prüfen** — jede Stufe beurteilt sich selbst, das Protokoll sammelt ein:

```
python pruefprotokoll.py schnell      rund eine Minute
python pruefprotokoll.py ganz         dazu die langen Läufe, rund eine halbe Stunde
```

**Einzelne Stufen** — jedes Programm läuft für sich und sagt RICHTIG oder FALSCH:

```
python sg_stempel.py                  der Zweigstempel gegen die geschlossene Lösung
python poiseuille.py                  ebener Kanal gegen Hagen-Poiseuille
python impuls_matrix.py               Impulsoperator: Matrix gegen Feldoperation
python drucknetz_koerper_probe.py     Drucknetz mit Störkörper und Ausstrom
python knotenregel_probe.py           Divergenz am Ende jedes Zeitschritts
python bild.py probe                  Wirbelstärke gegen Felder mit bekanntem omega
```

**Den unabhängigen zweiten Weg rechnen** — Galerkin, Taylor-Hood, körperangepasstes Netz:

```
python netz_fem.py                                 das Netz und seine Proben
python fem_galerkin.py                             Ansatzraum und Hagen-Poiseuille EXAKT
python fem_wirbelstrasse.py 0.0039 12 1.25e-4      trifft alle drei Intervalle
```

**Die Wirbelstraße rechnen** — Netz, Netz, Sekunden; das Feld wird mitgeschrieben:

```
python wirbelstrasse.py 220 41 12          grob,     rund  2 Minuten
python wirbelstrasse.py 440 82 12          mittel,   rund  5 Minuten
python wirbelstrasse.py 880 164 12         fein,     rund 70 Minuten
```

**Dieselbe Rechnung auf beiden Wegen** — Netzwerkmatrix gegen Feldoperation:

```
python wirbelstrasse_zweiwege.py 220 41 8
```

**Die Druckdifferenz**, die vierte Referenzgröße:

```
python druckdifferenz.py 440 82 12
```

**Das Labor bauen und prüfen**:

```
python baue_labor.py                 (im Ordner labor\)
node pruefe_kern.js                  Netzwerkkern gegen Python, 45 Posten
node pruefe_kern_fem.js              Galerkin-Kern gegen Python, 47 Posten
node pruefe_labor.js                 Knopfprobe im echten Browser
python surrogat.py 220 41 12 2.5 16  Surrogat neu anlernen (dauert ~35 min)
```

**Das Bild**:

```
python schaubild.py feld_880x164.npz wirbelstrasse_schaubild.png

```

# Woran man erkennt, ob es stimmt

Nicht daran, dass etwas ohne Fehlermeldung durchläuft. Jedes Programm endet mit einer
Zeile `== n/m` und mit dem Rückgabewert 0 oder 1. Die Referenzwerte stammen aus dem
Schäfer-Turek-Benchmark (DFG 1996) und sind nicht anpassbar:

| Größe | Referenz |
|:--|:--|
| $c_D^{\max}$ | 3,22 … 3,24 |
| $c_L^{\max}$ | 0,99 … 1,01 |
| $\mathrm{St}$ | 0,295 … 0,305 |
| $\Delta p$ | 2,46 … 2,50 |

Ein einzelner Lauf, der zufällig im Intervall liegt, ist kein Nachweis. Nachgewiesen wird
über die **Netzverfeinerungsreihe**: Jede Größe muss mit feinerem Netz näher an die
Referenz kommen, und der aus drei Stufen extrapolierte Grenzwert muss hineinfallen.
